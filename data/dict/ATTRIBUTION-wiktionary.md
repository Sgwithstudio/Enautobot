# Wiktionary data
`dict.db` (built by `scripts/build-dict.js`) also contains English glosses, IPA and Vietnamese translations extracted from
Wiktionary by Tatu Ylonen's wiktextract project (https://kaikki.org). Wiktionary text is available under
CC BY-SA 4.0 and GFDL; contributors are listed in the edit history of each Wiktionary page.
The Vietnamese definitions and examples come from the dataset described in `ATTRIBUTION.md`.
The combined database is shared under CC BY-SA 4.0.
